# GEMS Training Academy

Learn-on-the-go training for Exotel and the GEMS Admissions CRM. Static site for GitHub Pages, no build step.

- **Admin handbook** (`assets/js/admin.js`): for the Exotel + CRM owner. Exotel admin (add counsellor, group, flow, number, spam, leave), CRM telephony setup, sales flow, status meanings, quick views, common problems, running a training.
- **Train a counsellor** (`assets/js/content.js` + `content-extra.js`): screen-share presenter, one step per screen with clip, bullet steps and a question to ask. Arrow keys move; Full screen hides the header.
- **Quizzes**: admin quizzes plus one quiz per counsellor module and a final mix. Pass mark in `assets/js/config.js`. Best scores are kept on the device only.

Screenshots in `assets/img/exo-*.jpg` and `crm-agent-*.jpg` are from the 10 Nov 2026 onboarding call, with names, emails and phone numbers blurred. Keep personal data and logins off this site: it is public.
